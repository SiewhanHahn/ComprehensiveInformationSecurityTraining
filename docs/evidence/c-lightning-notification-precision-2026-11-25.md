# H4 验收：雷电通知显示快照中的 LTNG 峰值

基线 `76f9c0a`。修订仅影响新生成的雷电通知摘要，不修改预测规则、阈值、已存研判快照、已有通知或数据库结构。显示规则与雷电证据卡一致：两位小数足以表示原值时用两位；否则保留快照中的更细精度。

- **内置案例：**圣路易斯 KSTL 的历史预报峰值为 `0.09`（无量纲，不是概率）。旧版在撤回通知实际显示 `0.1`。新版本经过不同账号制单、审核和发布后，订阅者的发布与撤回通知、分析员的任务指派通知均显示 `6 小时最大 LTNG 0.09 无量纲`，与详情快照一致。
- **格式边界：**独立检查 `0.09 → 0.09`、`0.1 → 0.10`、`0.059 → 0.059`。不把更精细的已保存值截断到两位。全量套件同时覆盖原有台风 `144.3 km`、雪灾 `20.19 cm`，以及暴雨通知的 `29.6mm`。
