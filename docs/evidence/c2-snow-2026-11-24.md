### 演示提示

登录选择「数据 → 雪灾回放」。先看新奥尔良的原文件时间、累计量和气象站事后记录，再切两条济南对照。回到新奥尔良才可制单；雪灾值进结构化预报证据，不写入雨量字段。站码只核对降雪过程，不核验累计值、灾损或统计准确率。错误单位可用 `python -m pytest -q /app/tests/test_snow.py -k incompatible_units` 演示拒绝。

18481 仅用于隔离可写 QA；勿把它当正式演示入口或使用历史演示环境跑写入测试。有非降水草稿后不能仅降级 API 或单独降级迁移；应使用匹配的完整旧备份或原隔离实例。
