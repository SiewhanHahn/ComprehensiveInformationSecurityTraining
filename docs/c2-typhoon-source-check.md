# C2 台风：先核对数据，不计入 C1 功能验收

候选案例：香港天文台的台风「天鸽」（Hato，1713），2017-08-22 至 08-23。下列仅为后续实现的**数据可行性核对**；尚未实现台风预测入口、风险判断、审批或案例测试。未随源码分发原公报正文。

| 用途 | 核对结果（UTC，经纬度为北纬/东经） |
| --- | --- |
| 当时可用的输入 | 香港天文台航运公报签发：2017-08-22 18:30 HKT，即 10:30 UTC。公报所述 09:00 分析位置为 20.5°N、117.8°E。预报有效时间为 2017-08-23 09:00，位置为 22.4°N、112.1°E。 |
| 独立于预测输入的事后记录 | 香港天文台最佳路径表在 2017-08-23 09:00 UTC 列出 22.4°N、112.5°E（表中标注的额外时次，非整六小时行）。同一机构，不称独立观测来源。 |
| 时间口径 | 目标有效时刻距分析时刻 24 小时，距实际签发仅 22 小时 30 分钟。以签发为信息可用边界，不能标成“签发后精确 24 小时”。最佳路径只能用于核对，不得当作输入。 |

**原始资料：** [香港科技大学存档的香港天文台原始航运公报](https://envf.ust.hk/dataview/api_2dmap/current/display_winfo.py?file=%2Fdataop%2Fdata%2Fhko%2Fwebpages%2Fhourly%2F2017%2F201708%2F2017082211.hko.htm)（页面含多个产品，核对 *Tropical Cyclone Warning* 及其签发时刻）；[香港天文台天鸽最佳路径表](https://www.hko.gov.hk/en/publica/tc/tc2017/six_hrly_data_hato.html)。

**进入开发前还需做的事：** 明确定义“离城市最近”是离散预报点或插值路径的距离；不要把离散时刻的距离说成真实最近距离。说明坐标基准、有效区间、教学阈值依据与材料可再分发范围。选近、远两个地点，用同一次预报对照，并保留错过风险的可能性。一个案例不提供统计准确率。
