# C2 台风接近风险：实现与验收计划

**目标**：离线回放天鸽公报，演示近、远城市差异，只有内置案例的达标判断可创建台风演练草稿。继续复用 B 的独立审批、派单、通知、反馈、撤回和审计；C1 暴雨源数据、试算和指标不变。依据：[八灾种验收表](../../c-eight-hazard-acceptance.md)。

**取舍**：不把分析位置或事后轨迹补进预测，不在两个离散点之间假装实时轨迹。取实际签发后的 `(0, 24]` 小时内离散预报点，Haversine 球面距离（R=6371 km），取最小值，距离相等取较早时次；四舍五入到 0.1 km 后与团队自定的 200 km 教学阈值比较。无点返回不可判断，事后比较只匹配同一有效时刻。一个案例不报告准确率，不预测风圈、降雨或实际损失。

- [ ] 测试：验证广州 144.3 km、上海 1351.3 km、未来边界和缺测；天鸽实际最佳路径回查为 22.4°N、112.0°E，显示在单独的事后区域。出处带签发、有效、核对日期，保留少量数据事实、不分发原文。
- [ ] 接口：认证 `GET /typhoon/cases`、`GET /typhoon/cases/{case_id}/assessment?city_code=...`；`POST /warnings/typhoon` 仅 ANALYST/ADMIN、CSRF，接收案例/城市和草稿文本，服务端从受控数据重算，拒绝低于风险触发、缺测及额外字段；保存不可由草稿编辑改写的预报快照。
- [ ] 迁移 `0008_hazard_assessment`：`warning_results` 保留城市/日期/风险字段，支持独立结构化判定，非降水结果没有假 mm 或 FusionRun。现有雨量行可读；有新判定时降级前拒绝，测试复查旧结果与真实外键行为。
- [ ] 页面：以现有深色界面为底，青色距离为重点，签发时的数据与事后核验分栏，选择城市后自动重算；不展示全程无风险结论。达到阈值后可填草稿；详情用同一预报卡，不渲染雨量图。灾种矩阵更新为老师的八类、只标暴雨和台风已实现。
- [ ] 验收：同一已固定提交的干净归档与独立 Compose 卷；测试近/远、缺测、角色、草稿/审批/发布/响应/反馈/撤回与审计；回归 C1 和 B。保留版本号、测试输出和浏览器证据，不动历史实例，不推送。
